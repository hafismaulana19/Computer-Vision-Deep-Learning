# Computer Vision & Deep Learning

Repository ini berisi dokumentasi dan implementasi praktikum Computer Vision dan Deep Learning pada mata kuliah RET503.

## Daftar Praktikum

### P1 — Camera Calibration

Melakukan kalibrasi kamera menggunakan OpenCV untuk memperoleh parameter intrinsik kamera serta menguji proses undistorsi citra.

**Folder:** [`Kamera-Kalibrasi/`](Kamera-Kalibrasi/)

### P2 — Transfer Learning

Klasifikasi citra komponen elektronik **MG90S** dan **PCA9685** menggunakan pendekatan transfer learning. Praktikum mencakup pelatihan model, evaluasi, pengujian menggunakan data eksternal, serta perbandingan performa model.

**Folder:** [`Transfer-Learning/`](Transfer-Learning/)

## Teknologi

- Python
- OpenCV
- TensorFlow / Keras
- PyTorch
- NumPy
- Matplotlib
